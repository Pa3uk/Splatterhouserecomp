# Recomp Splatterhouse 2010 (Xbox360 ver.)

Пока еще (НЕ РЕЛИЗ) есть над чем поработать. Это своего рода просто АНОНС.
Это уже полноценный Портативный-рекомпиляторный билд+с DLC. Который работает. Вес самого рекомпилятора 18 МБ, вес игры 5.5 GB. Проделано много работы и тут текста не хватит что-бы я описал все правки что я сделал, сейчас задача сделать лаунчер и добавить все возможные настройки + попытаться реализовать отображение на экране ПК кнопок, т.е. что-бы видно было не X-Y-A-B , а именно что нужно нажать на клавиатуре.

It’s still a work in progress (NOT A RELEASE); there’s more to be done. Think of this simply as an ANNOUNCEMENT.
This is a fully functional, portable build—complete with a recompiler and all DLC. The recompiler itself is 18 MB, while the game weighs in at 5.5 GB. A great deal of work has gone into this; the current objective is to develop a launcher, incorporate a full range of settings, and—if possible—implement on-screen prompts that show the actual keyboard keys to press, rather than the standard X, Y, A, and B controller button labels
